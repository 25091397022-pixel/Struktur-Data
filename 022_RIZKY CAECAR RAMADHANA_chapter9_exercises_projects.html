9.1 Time Complexities – Sorted Doubly Linked List
Evaluate the four basic linked list operations for a sorted doubly linked list and indicate the worst case time-complexities of each.
▶ Jawaban
OperasiBest CaseWorst CasePenjelasan
Traversal Ω(1) O(n) Harus mengunjungi setiap node satu per satu menggunakan pointer next atau prev. Tidak bisa dipersingkat karena semua node harus dikunjungi.
Search Ω(1) O(n) Best case: target ada di head. Worst case: target tidak ada atau berada di akhir → seluruh list ditraversal. Dengan probe pointer, rata-rata lebih cepat namun worst case tetap O(n).
Insertion Ω(1) O(n) Best case: insert di head/tail (langsung, O(1) dengan tail reference). Worst case: posisi insert di tengah, perlu traversal O(n) untuk menemukan posisi. Setelah posisi ditemukan, pemasangan link prev/next cukup O(1) tanpa butuh pointer predecessor terpisah.
Deletion Ω(1) O(n) Best case: hapus head/tail (O(1) karena langsung diakses). Worst case: node yang dihapus berada di tengah dan perlu dicari terlebih dahulu O(n). Namun begitu node ditemukan, penghapusan cukup O(1) karena predecessor langsung diakses via prev.
💡 Keunggulan doubly vs singly: Deletion dari doubly linked list tidak memerlukan pointer pred terpisah — predecessor diakses langsung via node.prev. Ini menyederhanakan kode meski kompleksitas asimptotik tetap sama.

9.4 Kode – Unsorted Doubly Linked List (4 Operasi)
Provide the code to implement the four basic operations — traversal, search, insertion, deletion — for an unsorted doubly linked list.
▶ Implementasi Python
PYTHON · unsorted_doubly_linked_list.py
class DListNode:
    def __init__(self, data):
        self.data = data
        self.next = None
        self.prev = None


# ──────────────────────────────────────────────────
# 1. TRAVERSAL  –  O(n)
#    Kunjungi setiap node dari head ke tail.
# ──────────────────────────────────────────────────
def traversal(head):
    curNode = head
    while curNode is not None:
        print(curNode.data, end=" → ")
        curNode = curNode.next
    print("None")


# ──────────────────────────────────────────────────
# 1b. REVERSE TRAVERSAL  –  O(n)
#     Manfaatkan pointer prev, mulai dari tail.
# ──────────────────────────────────────────────────
def rev_traversal(tail):
    curNode = tail
    while curNode is not None:
        print(curNode.data, end=" → ")
        curNode = curNode.prev
    print("None")


# ──────────────────────────────────────────────────
# 2. SEARCH  –  O(n)
#    Unsorted: harus traversal penuh sampai ketemu.
#    Return node jika ditemukan, None jika tidak.
# ──────────────────────────────────────────────────
def search(head, target):
    curNode = head
    while curNode is not None:
        if curNode.data == target:
            return curNode          # ditemukan
        curNode = curNode.next
    return None                    # tidak ditemukan


# ──────────────────────────────────────────────────
# 3. INSERTION  –  O(1) di head, O(n) di posisi tertentu
#    Tiga kasus: list kosong, insert di head, insert di tail.
#    Return (head, tail) baru.
# ──────────────────────────────────────────────────
def insert_head(head, tail, value):
    """Sisipkan di depan (prepend) – O(1)."""
    newNode = DListNode(value)
    if head is None:              # list kosong
        return newNode, newNode
    newNode.next = head
    head.prev    = newNode
    return newNode, tail


def insert_tail(head, tail, value):
    """Sisipkan di belakang (append) – O(1) dengan tail ref."""
    newNode = DListNode(value)
    if tail is None:              # list kosong
        return newNode, newNode
    newNode.prev = tail
    tail.next    = newNode
    return head, newNode


def insert_after(head, tail, target_node, value):
    """Sisipkan setelah target_node – O(1) jika node sudah diketahui."""
    if target_node is None:
        return insert_head(head, tail, value)
    newNode = DListNode(value)
    newNode.next = target_node.next
    newNode.prev = target_node
    if target_node.next is not None:
        target_node.next.prev = newNode
    else:
        tail = newNode          # target_node adalah tail
    target_node.next = newNode
    return head, tail


# ──────────────────────────────────────────────────
# 4. DELETION  –  O(1) jika node diketahui, O(n) jika dicari
#    Manfaatkan prev/next untuk bypass node.
#    Return (head, tail) baru.
# ──────────────────────────────────────────────────
def delete_node(head, tail, target_node):
    """Hapus target_node dari list – O(1) karena akses prev/next langsung."""
    if target_node is None:
        return head, tail

    # Sesuaikan pointer tetangga
    if target_node.prev is not None:
        target_node.prev.next = target_node.next
    else:
        head = target_node.next   # target adalah head

    if target_node.next is not None:
        target_node.next.prev = target_node.prev
    else:
        tail = target_node.prev   # target adalah tail

    # Bersihkan pointer node yang dihapus
    target_node.next = target_node.prev = None
    return head, tail


def delete_value(head, tail, value):
    """Cari lalu hapus nilai tertentu – O(n) karena pencarian."""
    node = search(head, value)
    if node is None:
        return head, tail   # tidak ditemukan
    return delete_node(head, tail, node)
9.5 Kode – Delete dari Sorted Doubly Linked List
Provide the code to delete a node from a sorted doubly linked list.
▶ Implementasi Python
PYTHON · sorted_doubly_delete.py
# ──────────────────────────────────────────────────
# DELETE dari SORTED Doubly Linked List
# Bedanya dengan unsorted: kita bisa early-exit
# jika nilai yang dicari sudah terlewati (>target).
# ──────────────────────────────────────────────────

def delete_sorted(head, tail, value):
    """
    Hapus node dengan nilai 'value' dari sorted doubly linked list.
    Return (head, tail) yang sudah diperbarui.
    Kompleksitas: O(n) pencarian, O(1) penghapusan.
    """
    # Kasus 1: list kosong
    if head is None:
        return head, tail

    # Kasus 2: target ada di head
    if head.data == value:
        newHead = head.next
        if newHead is not None:
            newHead.prev = None
        else:
            tail = None         # list jadi kosong
        head.next = None
        return newHead, tail

    # Kasus 3: target ada di tail
    if tail.data == value:
        newTail = tail.prev
        newTail.next = None
        tail.prev = None
        return head, newTail

    # Kasus 4: cari di tengah list
    # Karena sorted, bisa early-exit jika node.data > value
    curNode = head.next
    while curNode is not None and curNode.data <= value:
        if curNode.data == value:
            # Bypass curNode menggunakan prev dan next langsung
            # → tidak perlu pointer predecessor terpisah!
            curNode.prev.next = curNode.next
            curNode.next.prev = curNode.prev
            curNode.next = curNode.prev = None
            return head, tail
        curNode = curNode.next

    # Nilai tidak ditemukan dalam list
    return head, tail
💡 Keunggulan utama doubly linked list saat deletion: Karena setiap node menyimpan pointer prev, kita dapat mengakses predecessor secara langsung tanpa variabel pred tambahan yang biasa diperlukan di singly linked list.
9.6 Kode – Delete dari Sorted Singly Circular Linked List
Provide the code to delete a node from a sorted singly linked circular list.
▶ Implementasi Python
PYTHON · circular_delete.py
# ──────────────────────────────────────────────────
# DELETE dari SORTED SINGLY CIRCULAR Linked List
#
# Konvensi (sesuai buku):
#   listRef  → node TERAKHIR (last node)
#   listRef.next → node PERTAMA (first node)
#
# 4 kasus: (1) list kosong  (2) satu node
#          (3) hapus head   (4) hapus tengah/tail
# ──────────────────────────────────────────────────

def delete_circular(listRef, value):
    """
    Hapus node dengan nilai 'value' dari sorted circular list.
    Return listRef yang sudah diperbarui.
    Kompleksitas: O(n) pencarian, O(1) penghapusan.
    """
    # Kasus 1: list kosong
    if listRef is None:
        return None

    # Kasus 2: hanya satu node
    if listRef.next is listRef:
        if listRef.data == value:
            listRef.next = None
            return None       # list jadi kosong
        return listRef        # nilai tidak ditemukan

    # Kasus 3: hapus node PERTAMA (head = listRef.next)
    if listRef.next.data == value:
        listRef.next = listRef.next.next   # loopback dari last ke node ke-2
        return listRef

    # Kasus 4: cari di tengah atau di tail (listRef sendiri)
    # predNode melacak node sebelum curNode (diperlukan karena singly)
    predNode = listRef.next          # mulai dari first node
    curNode  = predNode.next         # mulai pencarian dari node ke-2
    done     = False

    while not done:
        if curNode.data == value:
            predNode.next = curNode.next   # bypass curNode
            # Jika yang dihapus adalah listRef (last node),
            # perbarui listRef ke predNode
            if curNode is listRef:
                listRef = predNode
            curNode.next = None
            return listRef
        # Early exit: karena sorted, jika curNode.data > value → tidak ada
        done = (curNode is listRef) or (curNode.data > value)
        predNode = curNode
        curNode  = curNode.next

    return listRef     # nilai tidak ditemukan
💡 Pada singly circular list, kita masih perlu pointer predNode untuk menyambung ulang chain. Inilah yang membedakannya dari doubly linked list dimana deletion cukup O(1) tanpa predecessor pointer.

class _EditBufferNode:
    """Node dalam doubly linked list; menyimpan satu baris teks."""
    def __init__(self, text):
        self.text = text    # list of char, selalu diakhiri '\n'
        self.prev = None
        self.next = None


class EditBuffer:
    """
    Edit Buffer ADT — doubly linked list of char-lists.
    Setiap node = satu baris; setiap baris diakhiri '\n'.
    """

    def __init__(self):
        first = _EditBufferNode(['\n'])
        self._firstLine   = first
        self._lastLine    = first
        self._curLine     = first
        self._curLineNdx  = 0       # indeks baris (0-based)
        self._curColNdx   = 0       # indeks kolom dalam baris
        self._numLines    = 1
        self._insertMode  = True

    # ── Status ──────────────────────────────────────────────────
    def numLines(self):    return self._numLines
    def numChars(self):    return len(self._curLine.text)
    def lineIndex(self):   return self._curLineNdx
    def columnIndex(self): return self._curColNdx
    def getChar(self):     return self._curLine.text[self._curColNdx]
    def inInsertMode(self):return self._insertMode

    def getLine(self):
        return "".join(self._curLine.text)

    def setEntryMode(self, insert):  self._insertMode = insert
    def toggleEntryMode(self):       self._insertMode = not self._insertMode

    # ── Cursor Movement ─────────────────────────────────────────
    def moveUp(self, nlines=1):
        if nlines <= 0: return
        nlines = min(nlines, self._curLineNdx)
        for _ in range(nlines):
            self._curLine = self._curLine.prev
        self._curLineNdx -= nlines
        if self._curColNdx >= self.numChars():
            self.moveLineEnd()

    def moveDown(self, nlines=1):
        if nlines <= 0: return
        limit = self._numLines - 1 - self._curLineNdx
        nlines = min(nlines, limit)
        for _ in range(nlines):
            self._curLine = self._curLine.next
        self._curLineNdx += nlines
        if self._curColNdx >= self.numChars():
            self.moveLineEnd()

    def moveDocHome(self):
        self._curLine    = self._firstLine
        self._curLineNdx = 0
        self._curColNdx  = 0

    def moveDocEnd(self):
        self._curLine    = self._lastLine
        self._curLineNdx = self._numLines - 1
        self._curColNdx  = 0

    def moveLineHome(self): self._curColNdx = 0
    def moveLineEnd(self):  self._curColNdx = self.numChars() - 1

    def moveLeft(self, steps=1):          # Project 9.2: terima int
        for _ in range(steps):
            if self._curColNdx > 0:
                self._curColNdx -= 1
            elif self._curLineNdx > 0:
                self.moveUp(1)
                self.moveLineEnd()

    def moveRight(self, steps=1):         # Project 9.2: terima int
        for _ in range(steps):
            if self._curColNdx < self.numChars() - 1:
                self._curColNdx += 1
            elif self._curLineNdx < self._numLines - 1:
                self.moveDown(1)
                self.moveLineHome()

    # ── Buffer Modification ─────────────────────────────────────
    def breakLine(self):
        nlContents = self._curLine.text[self._curColNdx:]
        del self._curLine.text[self._curColNdx:]
        self._curLine.text.append('\n')
        newLine = self._insertNode(self._curLine, nlContents)
        self._curLine    = newLine
        self._curLineNdx += 1
        self._curColNdx  = 0

    def addChar(self, char):
        if char == '\n':
            self.breakLine()
            return
        ndx = self._curColNdx
        if self.inInsertMode():
            self._curLine.text.insert(ndx, char)
        else:
            if self.getChar() == '\n':
                self._curLine.text.insert(ndx, char)
            else:
                self._curLine.text[ndx] = char
        self._curColNdx += 1

    def deleteChar(self):
        if self.getChar() != '\n':
            self._curLine.text.pop(self._curColNdx)
        else:
            if self._curLine is self._lastLine:
                return
            nextLine = self._curLine.next
            self._curLine.text.pop()
            self._curLine.text.extend(nextLine.text)
            self._removeNode(nextLine)

    def ruboutChar(self):
        if self._curColNdx > 0:
            self._curColNdx -= 1
            self._curLine.text.pop(self._curColNdx)
        elif self._curLineNdx > 0:
            prevLine = self._curLine.prev
            prevLen  = len(prevLine.text) - 1
            prevLine.text.pop()                      # hapus '\n' di prev
            prevLine.text.extend(self._curLine.text)
            self._removeNode(self._curLine)
            self._curLine    = prevLine
            self._curLineNdx -= 1
            self._curColNdx  = prevLen

    def deleteLine(self):
        if self._numLines == 1:
            self._curLine.text = ['\n']
            self._curColNdx = 0
            return
        toRemove = self._curLine
        if self._curLine is not self._lastLine:
            self._curLine    = self._curLine.next
        else:
            self._curLine    = self._curLine.prev
            self._curLineNdx -= 1
        self._curColNdx = 0
        self._removeNode(toRemove)

    def truncateLine(self):
        del self._curLine.text[self._curColNdx:]
        self._curLine.text.append('\n')
        self._curColNdx = len(self._curLine.text) - 1

    def deleteAll(self):
        self.__init__()

    # ── Project 9.3 Methods ─────────────────────────────────────
    def getPage(self, first, last):
        """Return list of strings [first...last] (0-based line indices)."""
        result  = []
        cur     = self._firstLine
        lineNum = 0
        while cur is not None and lineNum <= last:
            if lineNum >= first:
                result.append("".join(cur.text))
            cur     = cur.next
            lineNum += 1
        return result

    def insertString(self, s):
        """Masukkan string s mulai dari posisi cursor saat ini."""
        for ch in s:
            self.addChar(ch)

    def moveTo(self, lineNdx, colNdx):
        """Pindah cursor ke posisi (lineNdx, colNdx). Validasi otomatis."""
        if lineNdx < 0 or lineNdx >= self._numLines:
            return
        # Navigasi ke baris yang dituju
        diff = lineNdx - self._curLineNdx
        if   diff > 0: self.moveDown(diff)
        elif diff < 0: self.moveUp(-diff)
        # Set kolom, clamp ke akhir baris jika colNdx > panjang
        self._curColNdx = min(colNdx, self.numChars() - 1)

    # ── Private Helpers ─────────────────────────────────────────
    def _insertNode(self, afterNode, text):
        """Sisipkan node baru setelah afterNode. Return node baru."""
        newNode      = _EditBufferNode(text)
        newNode.prev = afterNode
        newNode.next = afterNode.next
        if afterNode.next is not None:
            afterNode.next.prev = newNode
        else:
            self._lastLine = newNode
        afterNode.next = newNode
        self._numLines += 1
        return newNode

    def _removeNode(self, node):
        """Hapus node dari doubly linked list."""
        if node.prev is not None:
            node.prev.next = node.next
        else:
            self._firstLine = node.next
        if node.next is not None:
            node.next.prev = node.prev
        else:
            self._lastLine = node.prev
        node.prev = node.next = None
        self._numLines -= 1
